# Морзянка: знаки препинания

Тренажёр кодов **знаков препинания** русской и международной азбуки Морзе. Только знаки препинания — буквы и цифры здесь не нужны.

**[▶ Открыть тренажёр](https://aicfox.github.io/morse-punctuation/)** · один HTML-файл · без регистрации · работает офлайн

*English: an offline trainer for Morse code punctuation marks (Russian and International), with mnemonic chants, lessons and by-ear drills.*

## Возможности

- **Таблица** — коды и напевы, строки с различиями русской и международной азбуки подсвечены. Нажмите на строку, чтобы услышать код.
- **Урок** — знаки добавляются по одному: показ и звучание, затем проверка на слух. Следующий знак открывается после трёх верных ответов подряд для каждого изученного.
- **Знак → код**, **Код → знак**, **На слух** — каждый знак выпадает один раз в случайном порядке; ошибочные возвращаются позже.
- Две азбуки с отдельным прогрессом: **международная** и **русская**.
- Светлая и тёмная тема, адаптация под телефон, без внешних библиотек и сети.

## Знаки и коды

| Знак | Международная | Русская |
|:---:|:---:|:---:|
| `.` | `.-.-.-` | `......` |
| `,` | `--..--` | `.-.-.-` |
| `:` | `---...` | `---...` |
| `;` | `-.-.-.` | `-.-.-.` |
| `?` | `..--..` | `..--..` |
| `!` | `-.-.--` | `--..--` |
| `'` | `.----.` | `.----.` |
| `"` | `.-..-.` | `.-..-.` |
| `( )` | `-.--.-` | `-.--.-` |
| `-` | `-....-` | `-....-` |
| `/` | `-..-.` | `-..-.` |
| `=` | `-...-` | `-...-` |
| `@` | `.--.-.` | `.--.-.` |
| `+` | `.-.-.` | — |
| Ошибка | `........` | `........` |

Различаются точка, запятая, восклицательный знак и плюс. Знаки `!` и `@` не входят в первоначальный стандарт ITU и в разных справочниках записаны по-разному.

## Запуск

- **Онлайн:** откройте ссылку выше. В Chrome на телефоне можно нажать «Установить приложение» — тренажёр появится на главном экране и будет работать без сети.
- **Офлайн:** скачайте `index.html` и откройте в браузере двойным щелчком.
- **Локально:** `git clone https://github.com/aicfox/morse-punctuation.git`, затем откройте `index.html`.
